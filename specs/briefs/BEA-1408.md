# BEA-1408 — Brief First 4/6: the trial run (see the real thing before Create)

Part four of **Brief First**. Plan: <https://claude.ai/code/artifact/5c17fc65-a717-43b3-9bc6-4221968b0d94>
Linear: <https://linear.app/beakn/issue/BEA-1408>
Needs 3/6 (BEA-1407). **This is the gate that makes a wrong agent unable to reach the owner.**

## Why

Nine hours were lost because the owner approved a *description* of an agent. A description can lie.
A result cannot. From now on the last thing between the plan and Create is a real run on real data.

## Build

**`runKind: 'trial'`.** Before an agent can be created from a brief, the built program runs once, for
real, on the owner's account.

- **Small on purpose** — enough rows to judge, not the whole job. One page per source, a hard row cap
  and a hard credit ceiling for a trial. Seconds, not hours.
- **Nothing is written anywhere.** No sheet, no document, no saved row. The output is held for the
  screen only.
- **Nothing is sent to anyone.** The outgoing message is **rendered on screen exactly as it would
  arrive**, not delivered. A "send it to me" button sends **one** message to the owner's own number
  and nowhere else. (Standing rules: never burst the owner's phone — Meta paces templates to an
  unengaged owner; never message anyone else from a test.)
- **The screen shows**: the real rows in a table · the real message in a bubble · the real credits
  spent · what the success check said · every step it took, in plain words.
- **Two buttons**: *Create it* — saves the agent, `useWorker: true`, and keeps the trial as the first
  entry in its history. *Send it back* — one sentence from the owner, appended to the transcript as
  `owner`, then rebuild.
- **Create is impossible without a passed trial** on the current brief version. Editing the brief
  invalidates the trial.
- A trial that fails shows the failure honestly — the error, the step, and what it was trying to do.
  It must never read as success.

## Acceptance (WHEN / MUST)

- WHEN a trial runs, NO document, sheet row or outgoing message MUST be written or sent (asserted
  with spies).
- WHEN a trial finishes, the screen MUST show real rows, the exact message text, and the real credit
  cost.
- WHEN the owner has not run a passing trial for the current brief version, Create MUST be refused
  with a plain reason.
- WHEN the brief is edited after a passing trial, the trial MUST be invalidated.
- WHEN the owner taps "send it to me", exactly ONE message MUST be sent, to the owner's number only.
- WHEN the trial's success check fails, the screen MUST say so plainly and Create MUST stay refused.
- WHEN a trial errors, the run MUST NOT be reported as done (the BEA-1377 / honest-runs rule).
- The screen MUST read correctly at **1180 and 390**, light and dark.
