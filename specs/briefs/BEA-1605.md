# BEA-1605 — Protect the clock

Linear: <https://linear.app/beakn/issue/BEA-1605>
Independent. Ships after BEA-1604.

## Why

`AgentScheduler` (`api/src/hermes/agent-scheduler.service.ts`) ticks every 60 s at ~L26 with `this.tick().catch(() => undefined)` — any throw is swallowed with no log line. Timezone comes from Setting `tasks.tz` (~L31-34) and is fed to `Intl.DateTimeFormat(..., { timeZone })` (~L37). A name Intl rejects → `RangeError` on every tick → ALL scheduled agents stop silently, forever. `AgentService.setEngineSettings` (~L474-497) has no `timezone` key, so the UI cannot repair the value. `FlowScheduler` (`api/src/flows/flow-scheduler.service.ts`) is a near-copy with the same shape.

## What to build

1. Tick errors are logged (`log.error`, once per distinct message to avoid a 60 s flood), never swallowed silently; the next tick still runs.
2. Timezone resolution: validate the setting by trying `new Intl.DateTimeFormat(undefined, { timeZone: tz })`; on failure fall back to `Asia/Kolkata`, log a warning naming the bad value once, and raise ONE plumbing ops-alert through `ops-alert.ts` (BEA-1581 — classified by `failure-words.ts`, never a hand-named class; if the classifier has no fitting class, add the string to the classifier's data, not inline).
3. ONE shared helper (e.g. `api/src/hermes/schedule-clock.ts`: `safeTz(setting)` + `guardedTick(name, fn)`) used by BOTH `AgentScheduler` and `FlowScheduler`. Not a second copy.
4. Optional: a `debug`-level "tick: N schedulable, M due" line.

## Acceptance (WHEN / MUST)

- WHEN `tasks.tz` is `"Asia/Kolkatta"` (typo), the tick MUST still fire an agent due at the right IST minute and MUST log a warning once.
- WHEN a tick throws for another reason, the error MUST appear in the log and the next tick MUST still run.
- Locking tests: agent-scheduler spec (bad tz → still fires; thrown tick → logged, next tick ok), flow-scheduler spec (same two), a source test that both schedulers import the shared helper (match on the import, not a comment word).
- MUST NOT change `matches()`, the look-back, `markFired`, the lock skip, or any run road. The existing Monday 08:00 IST case MUST stay green.
